# qq-agent-skills

QQ Agent 自定义技能合集。

## pixiv-image-tagsearch

按角色/主题从 Pixiv 搜高收藏图并发到会话：多标签 AND 检索（角色＋壁纸等主题词）、热度档阶梯下调（当前档没有新图自动降 100 收藏一档）、按词条记忆档位、绝不重发已发过的图、默认优先最新作品。

### 安装

把 `skills/pixiv-image-tagsearch` 整个文件夹复制到 QQ Agent 应用的 `resources\app\skills\` 目录，重启 QQ Agent（或等技能热重载）。首次使用请在技能设置里把代理改成本机可用的代理地址。
